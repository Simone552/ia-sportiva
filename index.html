Collegamento reale 1 · football-data.org

Piano gratuito

Questo collegamento prova a leggere calendari e risultati della Champions League usando la tua chiave API. Il piano gratuito offre dati di base e punteggi/programma ritardati: non fornisce tutti i tiri, corner e falli.

Il token football-data.org deve essere salvato come Secret chiamato FOOTBALL_DATA_TOKEN nel Worker Cloudflare, non qui nel browser. Prima crea il Worker usando il file di codice fornito. Questo campo contiene solo l'indirizzo pubblico del Worker.

Procedura: Cloudflare Dashboard → Workers & Pages → Create → Worker → Edit code. Incolla il contenuto del file football-data-proxy.js, distribuiscilo, poi in Settings → Variables and Secrets aggiungi un Secret chiamato FOOTBALL_DATA_TOKEN con il tuo token e ridistribuisci se richiesto.
